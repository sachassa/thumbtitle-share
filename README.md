# 썸네일 제목 글자 재현 — 비교 화면

내부 연구용 비교 자료 · 썸네일 저작권은 각 채널에

유튜브 썸네일 속 제목 글자를 **같은 글꼴로 똑같이 다시 그려** 원본과 겹쳐 보는 연구 자료입니다. 이 저장소에는 결과 화면(HTML)과 그 화면이 쓰는 그림만 있습니다. 프로그램 코드·글꼴 파일·내부 자료는 없습니다.

| [최종 화면 — 부대찌개](index.html) | 캐나다 이웃집에 스팸 듬뿍 들어간 부대찌개를 냄비째 들고 갔더니ㅋㅋㅋ |

## 판정 기준

- 「일치」는 잰 값(글자 모양 겹침·크기·자리·색)이 **모두 원본과 100% 같을 때만**입니다. 봐주는 범위가 없습니다.
- 「완료」는 재현 → 따로 만든 검수 도구로 재기 → 색 겹침 그림 → 사람(Claude)이 원래 크기로 직접 보기를 다 했다는 뜻입니다. 결과는 「완료 · 100% 일치」 또는 「완료 · 일치 안 됨」으로 따로 적습니다.

## 글꼴 찾기·맞추기 방법

| 단계 | 하는 일 |
|---|---|
| 1. 글자 읽기 | 글자 인식 프로그램 두 가지(RapidOCR 한국어 모델, Windows 글자 인식)와 영상 제목·태그로 줄마다 글자를 확정 |
| 2. 글자 떼기 | 원본에서 글자 자리를 지우고 둘레 색으로 메워 「글자 없는 배경」을 만듦(OpenCV 메우기) |
| 3. 글꼴 찾기 | 후보 글꼴 약 1,600개로 같은 글자를 그려 원본과 겹쳐 보고, 겹침이 큰 순서로 좁힘. **제목 하나 = 글꼴 하나**: 줄마다 따로 찾지 않고 굵기·가로 비율·색·테두리는 효과로 맞춤 |
| 4. 두께 맞추기 | 원본 화소마다 「배경과 글자색 사이 어디쯤인지(0~1)」를 재고, 그린 글자가 같은 진하기가 되도록 굵기(0.05px 단위)·크기·가로·세로·글자마다 자리(1/8px 단위)를 조금씩 바꿔 가며 맞춤 |
| 5. 테두리 | 글자 바깥으로 거리마다 원본이 얼마나 어두운지 재서 그 진하기 그대로 그림 |
| 6. 검수 | 재현 프로그램의 값을 보지 않는 검수 도구가 원본과 재현을 같은 방법으로 따로 잼 |
| 7. 눈 확인 | 원본·재현·색 겹침(흰색 = 둘 다, 자홍 = 원본에만, 초록 = 재현에만)을 원래 크기로 봄 |

## 쓴 도구

| 도구 | 하는 일 | 이용 조건 |
|---|---|---|
| RapidOCR (onnxruntime) + PaddleOCR 한국어 인식 모델(PP-OCRv4) | 글자 읽기 | Apache 2.0 |
| Windows 글자 인식(Windows.Media.Ocr) | 글자 읽기 보조 | Windows 기본 기능 |
| OpenCV | 글자 자리 메우기, 거리 계산, 겹침 재기 | Apache 2.0 |
| Pillow · NumPy | 글자 그리기, 계산 | MIT-CMU · BSD |
| fontTools | 글꼴에 그 글자가 있는지 확인 | MIT |
| 산돌구름 이미지 폰트 검색 | 유료 글꼴 이름 대조(글자 줄만, 허락된 범위에서만, 결과 그림은 받지 않음) | 산돌구름 이용 약관 |
| 직접 짠 프로그램(글꼴 겹쳐 보기·두께 맞추기·검수) | 위 3~6단계 | 공개하지 않음 |

외부 AI에 썸네일을 넣어 그림을 만들거나, 글꼴 찾기 사이트에 썸네일을 올리지 않았습니다.

## 쓴 글꼴 (글꼴 파일은 넣지 않음)

화면에 나온 글꼴만 적었습니다. 후보로 비교한 전체 글꼴은 [결과](결과.md)에 개수만 있습니다.

| 글꼴 | 어디에 | 받은 곳 | 이용 조건 |
|---|---|---|---|
| 페이퍼로지 8 ExtraBold | 부대찌개 제목 | 눈누 웹폰트 저장소(jsDelivr `projectnoonnu`) | 무료 글꼴로 배포됨 — 원 배포처 조건 확인 필요 |
| 페이퍼로지 2 ExtraLight | 조니 뎁 윗줄(대신 쓴 것) | 같음 | 같음 |
| 지마켓 산스 Medium | 조니 뎁 제목 | 눈누 웹폰트 저장소 | 상업 사용 무료(지마켓) |

조니 뎁 윗줄은 지마켓 산스 Light로 보이지만 이 PC에 없어서 비슷한 글꼴로 대신 그렸습니다.
